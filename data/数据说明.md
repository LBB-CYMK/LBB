# 数据说明

> 课程设计：基于深度学习的设备磨损趋势预测与故障预警系统

## 一、数据来源

本阶段数据采用**自建数据集**（指数磨损模拟数据），数据量小（约 1.2 万条），
按课程要求**直接提交到仓库 `/data` 目录**下，无需上传 HuggingFace / ModelScope。

### 1. 数据生成原理

设备磨损量随运行时间呈**指数退化**趋势，是剩余使用寿命（RUL）预测领域的经典退化模型：

```
w(t) = w0 + A · (exp(B·t) − 1) + ε
```

| 符号 | 含义 | 取值范围 |
|------|------|----------|
| w0 | 初始磨损量（mm） | U(0.03, 0.08) |
| A  | 退化幅值系数 | U(0.003, 0.010) |
| B  | 指数退化速率 | U(0.008, 0.020) |
| ε  | 观测噪声 | N(0, 0.004²) |

每个设备（unit）随机采样一组 (w0, A, B)，拥有不同的退化轨迹与寿命；
当磨损量 w(t) 达到失效阈值 `1.0 mm` 时判定设备失效。同时生成与磨损相关的
温度信号（T = T0 + k·w + 噪声），构成**多特征时序数据**。为验证异常检测流程，
在原始数据中随机注入约 1.5% 的传感器野值（跳变/跌落）。

## 二、数据文件说明

```
data/
├── raw/                         # 原始数据（未处理）
│   ├── wear_raw.csv             # 原始磨损数据（含异常值）
│   └── units_summary.csv        # 各设备退化参数与寿命汇总
└── processed/                   # 预处理后数据
    ├── wear_processed.csv       # 清洗 + 归一化后的完整数据
    ├── sequences.npz            # 滑动窗口时序样本（训练/测试，供 RNN 训练）
    ├── preprocess_report.json   # 预处理统计报告
    └── preprocess_visualization.png  # 异常值剔除前后对比图
```

### 1. `data/raw/wear_raw.csv`（原始数据）

| 字段 | 类型 | 含义 |
|------|------|------|
| unit_id | int | 设备编号（1~30） |
| time_cycle | int | 运行周期（时间步） |
| wear_value | float | 磨损量（mm） |
| temperature | float | 温度（℃） |

共 30 台设备、12000 条样本，设备寿命范围 244 ~ 597 周期（均值 399）。

### 2. `data/processed/wear_processed.csv`（预处理后数据）

在原始字段基础上新增：

| 字段 | 含义 |
|------|------|
| wear_clean / temp_clean | 异常值剔除（回填）后的磨损量 / 温度 |
| wear_norm / temp_norm | Min-Max 归一化到 [0,1] 后的特征 |
| is_outlier | 是否被判定为异常值（布尔） |
| rul | 剩余使用寿命标签（分段线性，上限 125） |

### 3. `data/processed/sequences.npz`（时序样本）

用滑动窗口（窗口长度 20）将每个设备的时序切成样本：

- `X_train` / `X_test`：形状 (样本数, 20, 2)，2 维特征 = [wear_norm, temp_norm]
- `y_train` / `y_test`：下一周期的磨损量（回归目标）
- `rul_train` / `rul_test`：对应时刻的 RUL 标签

按设备划分训练集（24 台）与测试集（6 台），避免同一设备样本泄漏。

## 三、数据预处理流程

由 `src/preprocess.py` 完成，整体流程：

```
原始数据 → 邻域中位数去趋势 + IQR 异常值剔除 → Min-Max 归一化
        → RUL 标签计算 → 滑动窗口样本构建 → 数据集划分
```

1. **异常值检测与剔除（去趋势 + IQR）**
   磨损量呈单调上升趋势，直接对原始值做 IQR 会把趋势尾部误判为异常。因此先用
   「两侧邻域中位数」估计局部趋势（对单调序列有效，且排除当前点避免野值干扰），
   得到近似同方差的残差，再对残差按标准 IQR 规则 `[Q1−1.5·IQR, Q3+1.5·IQR]` 判定，
   并用局部趋势值回填。共剔除异常值 405 个（磨损量 322、温度 281）。

2. **Min-Max 归一化**
   对清洗后的特征做 `(x − min) / (max − min)`，映射到 [0,1]，消除量纲差异。

3. **RUL 标签计算**
   按分段线性退化假设：`RUL = min(失效周期 − 当前周期, 125)`。

4. **滑动窗口样本构建**
   用前 20 个周期的特征预测下一周期磨损量，构成 RNN 训练样本。

5. **数据集划分**
   按设备划分训练/测试集（80% / 20%），避免数据泄漏。

## 四、复现方法

```bash
# 1. 生成原始数据
python src/generate_data.py

# 2. 预处理
python src/preprocess.py
```

依赖：Python 3.8+、numpy、pandas、matplotlib（`pip install numpy pandas matplotlib`）。
