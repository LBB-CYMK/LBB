# 基于深度学习的设备磨损趋势预测与故障预警系统

> 课程设计项目 —— 以设备运行时序数据为研究对象，通过数据清洗、归一化与深度时序模型（RNN），
> 实现设备磨损量趋势预测与剩余使用寿命（RUL）估算，自动识别异常磨损并提前输出故障预警。
> 系统采用完整 B/S 架构：前端 UI + 后端 API + SQLite 数据库 + 算法模块。

## 一、项目简介

- **选题**：**面向旋转机械磨损型部件的退化趋势预测与预测性维护决策系统** —— 基于 RNN 时序建模的磨损量预测、剩余寿命(RUL)估算与三级故障预警
- **技术栈**：Python + Numpy / Pandas（数据处理）+ PyTorch（RNN）+ FastAPI（后端）+ SQLite（数据库）+ ECharts（前端）+ Matplotlib（可视化）
- **涉及课程专题**：数据预处理与异常值识别、循环神经网络时序预测（RNN/ReLU）、智能搜索与状态空间搜索、版本控制与工程部署
- **整体流程**：原始数据 → 异常值检测 → 归一化 → 时序样本构建 → RNN 训练 → 磨损预测 & RUL 计算 → 故障预警（含检修建议）

### 1. 应用场景

| 要素 | 具体内容 |
|---|---|
| **对象** | 旋转机械中的磨损型退化部件，以**数控机床主轴轴承**为参照对象；失效模式为**渐变型磨损失效**（可拟合、可预测） |
| **采集信号** | 按运行周期采集 **磨损量 w(t)**（mm，直接退化指标）+ **温度 T(t)**（℃，与磨损强相关的间接信号），构成 2 维多特征时序 |
| **失效判据** | 磨损量达到 **1.0 mm** 判定部件失效；30 台设备寿命落在 244 ~ 597 周期（均值 399） |
| **业务闭环** | 运维人员查看磨损趋势 → 系统输出 RUL 与三级预警 → 据此决策：**正常**按计划检修 / **预警**提前备件并安排近期停机检查 / **严重预警**立即停机检修 |

> 说明：本项目为课程设计，采用**自建仿真数据**建模，定位是「以该类部件为参照对象的建模与决策链路验证」，非真实产线部署。

### 2. 关键技术选型

| 维度 | 候选方案 | 选择 | 核心理由 |
|---|---|---|---|
| 数据来源 | C-MAPSS 真实数据 / **自建仿真** / 企业数据 | **自建指数退化数据** | 有磨损量真值、可控可复现，便于逐项验证每步算法是否真的起作用 |
| 预测模型 | **RNN** / LSTM / GRU / Transformer | **RNN + ReLU** | 窗口仅 20 步，梯度衰减不构成瓶颈；约 1.2 万条小数据宜用小参数量模型防过拟合 |
| 异常值检测 | 3σ / 全局 IQR / **去趋势+IQR** | **去趋势 + IQR** | 单调趋势下全局 IQR 会把尾部整段误判（实测误标约 19%）；去趋势后残差同方差 |
| RUL 估算 | 直接回归 / **滚动前向模拟** | **滚动前向模拟** | 复用同一套磨损预测权重，无需第二套模型或依赖假设得到的 RUL 标签 |
| 架构与技术栈 | C/S vs **B/S**；Flask vs **FastAPI**；MySQL vs **SQLite** | **B/S + FastAPI + SQLite** | 零安装易演示、自带 API 文档、零配置随项目走 |

> 完整的选型对比（含代价与局限）见 [方案设计.md](方案设计.md) 与 [选型与选题论证.md](选型与选题论证.md)。
> **诚实边界**：NASA C-MAPSS 仅作为公开数据对照来源提及，**未实际用于训练或验证**。

## 二、系统架构

```
浏览器前端 (web/index.html + ECharts)
        │  HTTP / REST API
        ▼
FastAPI 后端 (src/app.py)  ── 算法服务层 (src/predict.py) ── RNN 模型 (src/model.py)
        │ 读写
        ▼
SQLite 数据库 (src/database.py → data/app.db)
```

- **算法模块**：数据预处理（去趋势+IQR）、RNN 时序预测、超参数网格搜索（智能搜索）、滚动前向模拟估算 RUL（状态空间搜索）
- **后端服务**：FastAPI 提供 REST API，承载设备查询、预测、预警等业务逻辑
- **数据库**：SQLite 存储设备档案、预测记录、预警事件
- **前端 UI**：单页应用，走通「选设备 → 看曲线 → 预测 → 查看 RUL/预警」完整流程

## 四、数据来源

本阶段数据采用**自建数据集**（指数磨损模拟数据），数据量小（约 1.2 万条），
**直接提交到仓库 `/data` 目录**下，无需上传 HuggingFace / ModelScope。

数据基于经典指数退化模型生成：

```
w(t) = w0 + A · (exp(B·t) − 1) + ε
```

- 30 台设备（unit），每台设备随机采样退化参数 (w0, A, B)，寿命范围 244 ~ 597 周期；
- 磨损量达到失效阈值 `1.0 mm` 判定失效；同时生成与磨损相关的温度信号，构成多特征时序；
- 随机注入约 1.5% 的传感器野值，用于验证异常检测流程。

**公开数据集参考**（可选对比，均为有效镜像）：
- NASA C-MAPSS 涡扇发动机退化数据集（RUL 预测经典数据集）
  - GitHub 镜像：<https://github.com/edwardzjl/CMAPSSData>
  - Zenodo 存档：<https://zenodo.org/records/15346912>

> 详细数据来源说明见 [data/数据说明.md](data/数据说明.md)。

## 五、数据预处理

由 [src/preprocess.py](src/preprocess.py) 完成，流程如下：

```
原始数据 → 邻域中位数去趋势 + IQR 异常值剔除 → Min-Max 归一化
        → RUL 标签计算 → 滑动窗口样本构建 → 数据集划分
```

1. **异常值检测与剔除**：对单调趋势先用「两侧邻域中位数」去趋势，再对残差做标准 IQR 判定
   （`[Q1−1.5·IQR, Q3+1.5·IQR]`），并用局部趋势回填。共剔除 405 个异常值。
2. **Min-Max 归一化**：映射到 [0,1]，消除量纲差异。
3. **RUL 标签**：分段线性退化 `RUL = min(失效周期 − 当前周期, 125)`。
4. **滑动窗口样本**：窗口长度 20，用前 20 周期特征预测下一周期磨损量。
5. **数据集划分**：按设备 80% / 20% 划分训练/测试集，避免数据泄漏。

预处理后时序样本：训练集 `(9057, 20, 2)`、测试集 `(2343, 20, 2)`。

## 六、模型与预测

### 模型（[src/model.py](src/model.py)）
`WearRNN`：RNN 层（ReLU 激活，batch_first）→ 取最后时间步隐藏状态 → 全连接回归头，输出下一周期磨损量。

### 训练（[src/train.py](src/train.py)）
超参数网格搜索（`hidden_size × lr`，对应「智能搜索」专题）择优，最优配置在完整训练集上重训。
独立测试集指标：**MSE≈2.7e-5、RMSE≈0.0052、MAE≈0.0041**。

### 预测 / RUL / 预警（[src/predict.py](src/predict.py)）
- **磨损预测**：输入近 20 周期特征，单步前向预测下一周期磨损量。
- **RUL 估算**：滚动前向模拟（状态空间搜索）——反复预测并回填窗口，直到磨损越过失效阈值，所得周期数即为剩余寿命。
- **故障预警**：基于预测磨损量与 RUL 判定 normal / warning / critical 三级状态。

## 七、复现方法

```bash
pip install numpy pandas matplotlib torch fastapi uvicorn pytest

# 1. 生成原始数据
python src/generate_data.py

# 2. 数据预处理
python src/preprocess.py

# 3. 训练 RNN 模型（含超参数搜索）
python src/train.py

# 4. 运行自动化测试
python -m pytest

# 5. 启动系统，浏览器打开 http://127.0.0.1:8001
uvicorn src.app:app --reload
```
