# 基于深度学习的设备磨损趋势预测与故障预警系统

> 课程设计项目 —— 以设备运行时序数据为研究对象，通过数据清洗、归一化与深度时序模型（RNN），
> 实现设备磨损量趋势预测与剩余使用寿命（RUL）估算，自动识别异常磨损并提前输出故障预警。

## 一、项目简介

- **选题**：基于深度学习的设备磨损趋势预测与故障预警系统
- **技术栈**：Python + Numpy / Pandas（数据处理）+ PyTorch（RNN）+ Matplotlib（可视化）
- **涉及课程专题**：数据预处理与异常值识别、循环神经网络时序预测（RNN/ReLU）、智能搜索与状态空间搜索、版本控制与工程部署
- **整体流程**：原始数据 → 异常值检测 → 归一化 → 时序样本构建 → RNN 训练 → 磨损预测 & RUL 计算 → 故障预警

## 三、数据来源

本阶段数据采用**自建数据集**（指数磨损模拟数据），数据量小（约 1.2 万条），
**直接提交到仓库 `/data` 目录**下，无需上传 HuggingFace / ModelScope。

数据基于经典指数退化模型生成：

```
w(t) = w0 + A · (exp(B·t) − 1) + ε
```

- 30 台设备（unit），每台设备随机采样退化参数 (w0, A, B)，寿命范围 244 ~ 597 周期；
- 磨损量达到失效阈值 `1.0 mm` 判定失效；同时生成与磨损相关的温度信号，构成多特征时序；
- 随机注入约 1.5% 的传感器野值，用于验证异常检测流程。

**公开数据集参考**（可选对比，均为有效镜像）：
- NASA C-MAPSS 涡扇发动机退化数据集（RUL 预测经典数据集）
  - GitHub 镜像：<https://github.com/edwardzjl/CMAPSSData>
  - Zenodo 存档：<https://zenodo.org/records/15346912>

> 详细数据来源说明见 [data/数据说明.md](data/数据说明.md)。

## 四、数据预处理

由 [src/preprocess.py](src/preprocess.py) 完成，流程如下：

```
原始数据 → 邻域中位数去趋势 + IQR 异常值剔除 → Min-Max 归一化
        → RUL 标签计算 → 滑动窗口样本构建 → 数据集划分
```

1. **异常值检测与剔除**：对单调趋势先用「两侧邻域中位数」去趋势，再对残差做标准 IQR 判定
   （`[Q1−1.5·IQR, Q3+1.5·IQR]`），并用局部趋势回填。共剔除 405 个异常值。
2. **Min-Max 归一化**：映射到 [0,1]，消除量纲差异。
3. **RUL 标签**：分段线性退化 `RUL = min(失效周期 − 当前周期, 125)`。
4. **滑动窗口样本**：窗口长度 20，用前 20 周期特征预测下一周期磨损量。
5. **数据集划分**：按设备 80% / 20% 划分训练/测试集，避免数据泄漏。

预处理后时序样本：训练集 `(9057, 20, 2)`、测试集 `(2343, 20, 2)`。
